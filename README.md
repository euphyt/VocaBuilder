Needs Firebase, firebase tools, React
These could be installed through npm

This displays a daily word and the dictionary definition to that word.

The word is taken from the natural language tool kit(NLTK) and uses wordnet to get those words and definitions.

It uses a email and password for authentication and saves it to the firebase database.

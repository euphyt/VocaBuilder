# VocaBuilder 📚

VocaBuilder is a vocabulary learning web app that my team and I built for our **CSCE 3444 Software Engineering course at the University of North Texas**.

The goal of the project was to create a simple and interactive way for users to learn new words, keep track of words they've seen, save their favorites, and test what they've learned through quizzes.

## What You Can Do

With VocaBuilder, users can:

- Create an account and log in
- Discover and browse vocabulary words
- Browse words by difficulty level
- View their vocabulary history
- Save words to their favorites
- Remove words they no longer want saved
- Practice vocabulary through quizzes
- Listen to word pronunciations
- View definitions and parts of speech

## Built With

**Frontend:** React, TypeScript, Vite, HTML/CSS  
**Backend:** Python, FastAPI  
**Database:** Firebase Firestore  
**Authentication:** Firebase Authentication  
**Version Control:** Git and GitLab

Working on VocaBuilder gave me hands-on experience building a full-stack application with a team and seeing how the different pieces of a software project come together.

## How It Works

The frontend was built with **React and TypeScript**, while **Firebase Authentication** handles user accounts and **Firestore** stores vocabulary and user-specific data.

We also used **Python and FastAPI** for backend functionality.

## Running the Project

Clone the repository:

git clone https://github.com/euphyt/VocaBuilder.git

Install the dependencies:

npm install

Start the development server:

npm run dev
